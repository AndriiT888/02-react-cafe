# Cafe Feedback App

## 📌 Description

Cafe Feedback App is a React application that allows users to leave feedback about a coffee shop.  
Users can choose one of three feedback options: **good**, **neutral**, or **bad**, and view feedback statistics.

The application calculates the total number of feedback responses and the percentage of positive feedback.

## 🚀 Live Demo

[View Demo](https://02-react-cafe-lac-tau.vercel.app/)

## 🛠 Technologies

- React
- TypeScript
- Vite
- CSS

## ✨ Features

- Leave feedback using three options: good, neutral, bad
- Display feedback statistics
- Calculate total feedback
- Calculate positive feedback percentage
- Reset feedback statistics
- Responsive and simple user interface
